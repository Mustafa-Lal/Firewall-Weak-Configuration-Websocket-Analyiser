# Next-Gen-Firewall-Breacher

## 🚀 How to Run

### 1. **Download & Install Go**

If you don’t already have Go installed, download it from:
[https://go.dev/dl/](https://go.dev/dl/)

Make sure Go is added to your system PATH.

---

### 2. **Run the Application**

In the project folder, run:

```bash
go run main.go https_tunnel.go
```

This will start the proxy server.

---

### 3. **Set Your Proxy**

Configure your system or browser proxy to:

* **Host:** `localhost`
* **Port:** `8080`

---

### ✅ You’re Good to Go!

Your HTTPS tunnel proxy will now run and forward secure traffic through Go.
